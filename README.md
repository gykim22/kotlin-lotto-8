# kotlin-lotto-precourse

## 목표
- 간단한 로또 발매기를 구현하는 것을 목적으로 한다.
- 올바른 구입 금액을 입력받아 금액에 해당하는 개수의 로또를 발행한다.
- 6개의 당첨 번호와 1개의 보너스 번호를 사용자로부터 입력받는다.
- 발행된 로또와 당첨/보너스 번호와 비교하여 당첨 내역 및 수익률을 출력한다.
- 잘못된 입력에는 `IllegalArgumentException`을 발생시키고 `[ERROR]`로 시작하는 메시지를 출력한 뒤 해당 단계부터 `재입력`을 받는다.

## 입출력
### 입력
- 로또 구입 금액을 1,000원 단위로 입력받는다.
- 당첨 번호를 입력받는다. 구분자는 쉼표`,`로 한다.
- 보너스 번호를 입력받는다.
### 출력
- 발행한 로또 수량 및 번호 세트를 오름차순 정렬하여 출력한다.
- 발행한 로또 전체 당첨 내역을 출력한다.
- 소수점 둘째자리에서 반올림한 수익률을 출력한다.
- 예외 상황 시 `[ERROR]`로 시작하는 예외 문구를 출력한다.

## 필수 요구사항
- `Kotlin` 2.2.0에서 실행가능해야하며, 제공된 라이브러리 이외 라이브러리는 사용할 수 없다.
- `camp.nextstep.edu.missionutils` 라이브러리에서 제공하는 API를 활용한다.
    - `Console` API의 `readLine()`을 활용하여 문자열을 입력받는다.
    - `Randoms` API의 `pickNumberInRange()`를 활용하여 Random 값을 추출한다.
- 파일, 패키지 명과 위치를 유지하며, 코틀린 코드 컨벤션을 준수한다.

## 코드 구성
- MVC 구조를 활용하여 코드를 작성한다.
- 함수명을 명확히 한다.
- `SRP`를 따르고자 노력한다.

## 기능 구현
- [X] "구입금액을 입력해 주세요."를 출력한다.
- [X] 제공된 `Console` API의 `readLine()`을 활용하여 사용자 입력을 받는다.
  - [X] 입력에 따라 "n개를 구매했습니다."를 출력한다.
    - [X] 1000원 단위로 나누어 떨어지는 양의 자연수를 입력 받는다.
  - [X] "당첨 번호를 입력해 주세요."를 출력한다.
    - [X] 당첨 번호를 6개 입력받는다. 구분자는 쉼표`,`로 한다.
  - [X] "보너스 번호를 입력해 주세요."를 출력한다. 
    - [X] 보너스 번호를 1개 입력받는다.
- [X] 요구사항에 따라 결과를 출력한다.
  - [X] "당첨 통계\n---"를 출력한다. 
  - [X] 발행한 로또 수량 및 번호 세트를 오름차순 정렬하여 출력한다.
  - [X] 소수점 둘째 자리에서 반올림한 총 수익률을 출력한다.
- [X] 요구사항에 부합하지 않는 경우 `IllegalArgumentException` 등 명확한 예외를 발생시키고 다시 입력받는다.
